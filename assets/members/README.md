ACSES MEMBER PHOTOS
====================

Put one photo per member in this folder. The Members page will automatically
find the expected filename, so you do not need to edit page-members.js.

Recommended:
- JPG or PNG
- Portrait orientation (4:5 works well)
- One clear face / good lighting
- Keep each file reasonably small (around 300–800 KB is ideal)

Expected filename pattern (lowercase):
First Name Last Name -> first-name-last-name.jpg

Examples:
krish-mahajan.jpg
piyush-patil.jpg
sanika-kulkarni.jpg

git/github links and all member data remain in data.js.

If an image is not present yet, the website automatically shows the member's
initials instead of a broken image. When you add the image later, it appears
in the same photo frame automatically.
